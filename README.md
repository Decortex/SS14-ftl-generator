# space-station-14-ftl-generator
## Скрипт генерации локалей для прототипов. Если у вас есть большой прототип и вам не хочется тратить часы свой жизни на создание локализации, то скрипт может помочь облегчить вам непростую гмскую жизнь :3

### Как он работает?

Скрипт анализирует исходный yml и на его основе создает сгенерированную версию вместе с ftl. Всё ``¯\_(ツ)_/¯``

### Как им пользоваться?

1. Перекиньте скрипт в папку своего прототипа, желательно создать отдельную для него папку.
2. Создайте новую папку ``Source`` и закиньте туда yml. Можно несколько файлов закинуть если нужно.
3. Запустите скрипт. Он создаст папку ``Generated`` в которой находятся ваши сгенерированные файлы.
4. В игре с помощью команды ``UploadFolder`` выгрузите свой прототип на сервер. Далее ``Loadprototype`` и выбирайте сгенерированный yml.
5. Happy

Если скрипт не локализовал какие-то поля, то его нужно отредактировать. Просто добавьте новое поле локализации в самом скрипте вот тут: ``FORCE_LOCALIZE_FIELDS``  

Например, у нас игра жалуется на ошибку локализации ``briefingText`` и ``emptyLabel``.  

Ищем ``FORCE_LOCALIZE_FIELDS``.  

```
FORCE_LOCALIZE_FIELDS = {
    "unit",
    "toolName",
}
```
Добавляем сюда недостающее поле локализации. Ошибка должна исчезнуть.
```
FORCE_LOCALIZE_FIELDS = {
    "unit",
    "toolName",
    "briefingText",
    "emptyLabel",
}
```
